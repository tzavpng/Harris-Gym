# Χάρης Gym

Εφαρμογή γυμναστηρίου για iPhone: όργανα σε 3D, καταγραφή κιλών/επαναλήψεων, προγράμματα, θερμίδες.

- Ο κώδικας είναι στο `src/app.html`. Μετά από κάθε αλλαγή τρέχει `python3 build.py` και φτιάχνει το `index.html`.
- Το `index.html` το σερβίρει το GitHub Pages.
- Τα δεδομένα κάθε χρήστη μένουν μόνο στο κινητό του (localStorage).
